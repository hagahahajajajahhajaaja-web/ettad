# دليل المحتوى: المنتجات والصور والأسعار والسياسات

إلى أن تُبنى لوحة التحكم، المحتوى في ملفات TypeScript داخل `src/data/`. كل ملف موثّق من الداخل،
والبناء **يفشل** إذا كانت البيانات غير صالحة (معرّف مكرر، قسم غير موجود، سعر سالب، صور لمنتج غير موجود…).

## إضافة منتج

أضف كائنًا إلى `src/data/products.ts`:

```ts
{
  id: 'makita-hp-drill',             // معرّف ثابت للرابط والسلة: أحرف إنجليزية صغيرة وأرقام وشرطات
  name: 'اسم المنتج كما يظهر للعميل',
  brand: 'BRAND' /* أو null */,
  model: 'MODEL-1' /* أو null */,
  categoryId: 'power-tools',         // من src/data/categories.ts
  summary: 'وصف قصير وسهل بمعلومات مؤكدة فقط.',
  useLine: 'ربط البراغي والثقب في أعمال البيت', // استخدام المنتج في سطر قصير تحت الاسم في البطاقة (45 حرفًا كحد أقصى)
  uses: ['تركيب الأثاث', 'ربط وفك البراغي'], // «يُستخدم في» في صفحة المنتج (2–5)
  highlights: ['نقطة مختصرة 1', 'نقطة مختصرة 2'], // تظهر أعلى صفحة المنتج
  description: ['فقرة 1', 'فقرة 2'], // «عن المنتج» — اذكر مصدر أي رقم («حسب العلبة»)
  contents: ['الجهاز', 'بطاريتان'],  // محتويات العلبة/الطقم
  contentsSource: 'photo',           // store | packaging | marking | photo
  priceFils: null,                   // 12.500 د.ك = 12500 ؛ null = «استفسر عن السعر»
  availability: 'unconfirmed',       // 'in_stock' | 'out_of_stock' | 'unconfirmed'
  specs: [
    { label: 'القدرة', value: '800 واط', source: 'packaging' }, // تحت الجدول: «الأرقام حسب بيانات المصنع المطبوعة على العلبة»
  ],
  pendingVerification: ['العزم'],    // ما زال قيد التحقق — ملاحظة داخلية لا تظهر للعميل
  keywords: ['دريل', 'drill'],       // مرادفات للبحث
  imageAlts: ['علبة الدريل ...'],   // وصف دقيق لكل صورة (علبة أم المنتج نفسه؟)
  featured: false,                   // علامة تمييز للاستخدام لاحقًا (الرئيسية تعرض كل المنتجات)
  sortOrder: 10,                     // الترتيب في المتجر
  internalNotes: [],                 // لا تظهر في الموقع
  updatedAt: '2026-11-01',
}
```

**مصدر المعلومة (`source`)** يُحفظ مع كل مواصفة للتوثيق. يرى العميل سطرًا واحدًا تحت جدول المواصفات «الأرقام حسب بيانات المصنع المطبوعة على العلبة» إذا كانت أي مواصفة من العلبة:

| القيمة | متى تُستخدم |
| --- | --- |
| `store` | المتجر تحقق منها بنفسه أو ذكرها صاحب المتجر |
| `packaging` | منقولة حرفيًا من علبة المصنع |
| `marking` | مكتوبة على الجهاز أو البطارية |
| `photo` | تُرى بوضوح في صورة المنتج الفعلية |

لا تنقل عبارات تسويقية من العلبة (بلد الصنع، الضمان، «Professional»، «100% Copper»، أرقام البطاريات المبالغ فيها) حتى لو كانت مطبوعة عليها. الاختبارات الآلية تفشل إذا ظهرت هذه العبارات في النصوص المعروضة.

- القسم الذي لا يحتوي منتجات لا يظهر في الموقع (مثل «أطقم وأدوات الصيانة» حاليًا). بمجرد إضافة أول منتج له يظهر تلقائيًا في القوائم والـ Sitemap.
- **لا تغيّر `id` بعد الإطلاق** — يكسر روابط المنتج والسلال المحفوظة لدى العملاء.

## الأسعار والتوفر

**الطريقة المعتادة: من لوحة التحكم** (`/admin` ← «الأسعار والتوفر»). يظهر التغيير في المتجر خلال ثوانٍ، والطلبات الجديدة تُحسب بالسعر الحالي على الخادم.

`priceFils` و `availability` في `src/data/products.ts` قيم افتراضية فقط، تُستخدم قبل أول حفظ من اللوحة أو عند عدم توفر الخادم. السعر بالفلس كعدد صحيح: `7.250 د.ك` ← `7250`.
عند وجود منتج واحد مسعّر على الأقل تظهر تلقائيًا تصفية السعر وخيارات الترتيب بالسعر.
السلة لا تعرض «إجماليًا» إلا إذا كانت كل المنتجات فيها مسعّرة، ولا تضيف رسوم توصيل.

## الصور

1. ضع الصور الأصلية في `product-photos/<id>/` بأسماء مرتبة (`01.jpg`, `02.jpg` …). الأولى هي الرئيسية. سجّل مصدرها في `product-photos/SOURCES.md`.
   - لا تستخدم لقطات شاشة من إعلانات بائعين آخرين أو صورًا عليها علامات منصات (حراج، 4Sale…).
   - لقص عنصر ليس من الصورة (مثل ساعة الهاتف) أضف `edits.json` في نفس المجلد: `{ "02.jpg": { "trim": { "bottom": 64 }, "reason": "..." } }`.
2. شغّل `npm run images`.
3. السكربت يصحح الاتجاه ويحذف بيانات EXIF (الموقع/الكاميرا) ويصغّر إلى WebP بمقاسات 480/960/1600 **بدون قص أو تعديل للمنتج**، ويحدّث `src/data/product-images.json`.
4. اختياري: نص بديل مخصص لكل صورة عبر `imageAlts` في بيانات المنتج.

الصورة الأولى تُستخدم تلقائيًا كصورة مشاركة لرابط المنتج: نسخة JPEG ‏1200×630 مولدة (`01-og.jpg`)، لأن واتساب لا يعرض WebP دائمًا.

## السياسات

`src/data/policies.ts` — لكل سياسة حالة:

- `pending`: تعرض «قيد الإعداد» فقط ولا تنشر أي شروط، ومستبعدة من الـ Sitemap.
- `describes-current-operation`: نص يصف ما يفعله الموقع تقنيًا.
- `approved`: نص معتمد منك.

## الهوية

- الألوان والخطوط في `src/app/globals.css` (`@theme`).
- الشعار في `src/components/brand/Logo.tsx` و `src/app/icon.svg`. بعد تعديله شغّل `npm run brand` لتحديث الأيقونات وصورة المشاركة.
